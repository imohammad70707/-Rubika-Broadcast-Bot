# 🇬🇧 English

## 📌 About

**Rubika Broadcast Bot** is a Python-based bot designed to manage registered Rubika groups and send messages to multiple groups automatically.

The bot stores registered group information in a JSON file, allowing the data to remain available after restarting the bot. It also monitors each sending operation and provides a complete report of successful and failed deliveries.

## ✨ Features

* 🔗 Connect to Rubika using **Python + MAXRubika**
* 📝 Automatically register and save groups
* 📋 View the list of registered groups
* 📢 Broadcast messages to registered groups
* 📊 Show successful and failed delivery reports
* 🔄 Continue sending when a group returns an error or is inaccessible
* ❌ Cancel an active broadcast operation
* 📚 Built-in help section
* ⚙️ Management commands
* 💾 Persistent group storage using JSON

## ⚙️ How It Works

1. The bot connects to Rubika.
2. Groups are automatically registered and saved.
3. Registered groups can be viewed through the management commands.
4. An administrator starts a broadcast operation.
5. The bot sends the message to the registered groups.
6. Each result is checked individually.
7. Failed or inaccessible groups are skipped.
8. A final report containing the sending results is displayed.

## 💾 Data Storage

Registered group information is stored in a **JSON file**.

This allows the bot to preserve its registered groups even after restarting the program.

## 🛠️ Technology

* 🐍 Python
* 🤖 MAXRubika
* 📄 JSON

## ⚠️ Important Note

Use the broadcast functionality responsibly and only in groups where you have permission to send messages.

Avoid unwanted or excessive messaging and respect Rubika's rules and the permissions of each group.

# 🇮🇷 فارسی

## 📌 درباره پروژه

**Rubika Broadcast Bot** یک ربات پایتونی برای مدیریت گروه‌های ثبت‌شده در روبیکا و ارسال پیام به چندین گروه به‌صورت خودکار است.

اطلاعات گروه‌های ثبت‌شده داخل فایل **JSON** ذخیره می‌شود تا بعد از اجرای مجدد ربات نیز اطلاعات گروه‌ها باقی بماند.

سیستم ارسال همچنین نتیجه هر عملیات را بررسی کرده و در پایان، گزارش کاملی از ارسال‌های موفق و ناموفق ارائه می‌دهد.

## ✨ قابلیت‌ها

* 🔗 اتصال به روبیکا با **Python + MAXRubika**
* 📝 ثبت و ذخیره خودکار گروه‌ها
* 📋 مشاهده لیست گروه‌های ثبت‌شده
* 📢 ارسال همگانی پیام به گروه‌ها
* 📊 نمایش گزارش ارسال‌های موفق و ناموفق
* 🔄 ادامه ارسال در صورت خطا یا نداشتن دسترسی به یک گروه
* ❌ لغو عملیات ارسال
* 📚 دارای بخش راهنما
* ⚙️ دارای دستورات مدیریتی
* 💾 ذخیره دائمی گروه‌ها با استفاده از JSON

## ⚙️ نحوه عملکرد

1. ربات به روبیکا متصل می‌شود.
2. گروه‌ها به‌صورت خودکار ثبت و ذخیره می‌شوند.
3. لیست گروه‌های ثبت‌شده از طریق دستورات مدیریتی قابل مشاهده است.
4. مدیر عملیات ارسال همگانی را آغاز می‌کند.
5. ربات پیام را برای گروه‌های ثبت‌شده ارسال می‌کند.
6. نتیجه ارسال هر گروه به‌صورت جداگانه بررسی می‌شود.
7. گروه‌هایی که خطا داشته باشند یا دسترسی ارسال در آن‌ها وجود نداشته باشد، رد می‌شوند.
8. در پایان گزارش کامل وضعیت ارسال نمایش داده می‌شود.

## 💾 ذخیره اطلاعات

اطلاعات گروه‌های ثبت‌شده در یک فایل **JSON** ذخیره می‌شوند.

به این ترتیب، با ری‌استارت شدن ربات، اطلاعات گروه‌های قبلی از بین نمی‌رود.

## 🛠️ تکنولوژی‌های استفاده‌شده

* 🐍 Python
* 🤖 MAXRubika
* 📄 JSON

## ⚠️ نکته مهم

از قابلیت ارسال همگانی به‌صورت مسئولانه و فقط در گروه‌هایی استفاده کنید که اجازه ارسال پیام در آن‌ها را دارید.

از ارسال پیام‌های ناخواسته یا بیش‌ازحد خودداری کرده و قوانین روبیکا و دسترسی‌های هر گروه را رعایت کنید.
